# Official CodeRabbit brand assets

Retrieved September 5, 2026 for the maintainer-requested branding update. These are static files, not additional npm dependencies. Font license notices are bundled here. Preserve the logo artwork and font files without modification.

Source guidance: https://www.coderabbit.ai/brand

- `coderabbit-white.svg`: https://www.coderabbit.ai/content/assets/white-typemark.svg — official white logotype for dark surfaces.
- `geist-latin.woff2`: https://www.coderabbit.ai/_next/static/media/caa3a2e1cccd8315-s.p.0wgildi0cnwt9.woff2 — the brand site's Latin variable Geist font, 100–900. See `Geist-LICENSE.txt` (SIL OFL 1.1).
- `hack-regular.woff2`: https://www.coderabbit.ai/_next/static/media/hack_regular_subset-s.07d6et4x1fm36.woff2 — the brand site's regular Hack subset.
- `hack-bold.woff2`: https://www.coderabbit.ai/_next/static/media/hack_bold_subset-s.1x_5cpx2x_n3w.woff2 — the brand site's bold Hack subset. See `Hack-LICENSE.md` (MIT and Bitstream Vera notices).

Upstream font licenses: https://github.com/vercel/geist-font/blob/main/LICENSE.txt and https://github.com/source-foundry/Hack/blob/master/LICENSE.md.

The stylesheet uses exact CR Orange and dark Mauve hex tokens from the official brand page. Logo and font assets are served locally so the tour does not depend on third-party asset availability at runtime.
